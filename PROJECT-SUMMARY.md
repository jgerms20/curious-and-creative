## 🚀 How to Use This System

### For Simple Tasks (Single Agent)
1. Check **ROUTING-RULES.md** to identify the right agent
2. Review that agent's file for specific capabilities
3. Engage the agent with a clear request

**Example:**
```
Need: Social media posts about new product
Route to: Copywriter
Check: Creative/copywriter.md for guidance
Request: "Write 5 Instagram posts announcing our new product"
```

### For Complex Tasks (Multiple Agents)
1. Check **WORKFLOW-EXAMPLES.md** for similar scenarios
2. Use **AGENT-SKILLS.md** to find relevant orchestrations
3. Follow the multi-agent workflow pattern

**Example:**
```
Need: Launch campaign for new product
Pattern: campaign-development-workflow
Agents: Brand Strategist → Communication Strategist → Copywriter →
        Art Director → Production Manager → Data Strategist → Account Manager
Reference: WORKFLOW-EXAMPLES.md - Example 2
```

2. Check the decision tree

## 📊 Common Workflow Patterns

### Content Pattern
**Data → Brand → Copy → Art → Distribution**
Best for: Blog posts, articles, social content

### Campaign Pattern
**Brand → Comms → Creative (Copy + Art) → Production → Data**
Best for: Product launches, major campaigns

### Analysis Pattern
**Data → Strategy (Brand + Comms) → Presentation → Account**
Best for: Performance reviews, reporting

### Pitch Pattern
**Strategy + Data → Copy → Presentation → Account**
Best for: New business, proposals
