# Agent Routing Rules

## Overview
This document defines clear routing rules for delegating tasks to specialized agents within the marketing team. Use these rules to determine which agent(s) to engage based on request type, deliverable, and project phase.

---

## 🎯 Primary Routing Logic

### Request Analysis Framework
When a request comes in, analyze it using these questions:

1. **What is the primary deliverable?** (content, strategy, design, coordination, data analysis)
2. **What phase are we in?** (research, strategy, creative development, execution, measurement)
3. **Does this require multiple agents?** (single-agent task vs. multi-agent workflow)
4. **What's the time sensitivity?** (affects routing to Account Manager for coordination)

## 📋 Single-Agent Routing Rules

### Strategy Department

#### Communication Strategist
**Route when request includes:**
- Platform recommendations or specs (Instagram, TikTok, LinkedIn, etc.)
- Channel strategy or media mix planning
- Trending content analysis
- Cross-channel campaign architecture
- Media budget allocation
- OOH, TV, radio, audio, digital, social, email strategy

**Trigger Keywords:**
`platform`, `channel`, `media mix`, `trend`, `specs`, `social media strategy`, `OOH`, `media plan`, `what's working on [platform]`

**Example Requests:**
- "What platform should we use for this campaign?"
- "What's trending on TikTok right now?"
- "Create a media strategy for Gen Z"

## 🔄 Multi-Agent Workflow Routing

### Content Creation Workflow
**Trigger:** "Create [content type] about [topic]"

**Agent Sequence:**
1. **Brand Strategist** → Define messaging and brand alignment
2. **Communication Strategist** → Determine optimal platform/channel
3. **Copywriter** → Write the content
4. **Art Director** → Design visual elements
5. **Account Manager** → Coordinate review and approvals

**Example:** "Create a social media campaign about sustainability"

---

### Campaign Development Workflow
**Trigger:** "Develop a campaign for [objective/product]"

**Agent Sequence:**
1. **Brand Strategist** → Establish brand positioning and messaging
2. **Communication Strategist** → Define media strategy and channels
3. **Copywriter** → Develop creative concepts and copy
4. **Art Director** → Create visual concepts and design direction
5. **Production Manager** → Plan production logistics
6. **Account Manager** → Coordinate timeline and client approvals
7. **Data Strategist** → Define success metrics and measurement

**Example:** "Launch a new product campaign targeting millennials"

---

### Content Research & Blog Creation Workflow
**Trigger:** "Research [topic] and create a blog post"

**Agent Sequence:**
1. **Data Strategist** → Analyze topic trends, search data, audience insights
2. **Brand Strategist** → Define messaging angle and brand POV
3. **Copywriter** → Write the blog post
4. **Art Director** → Create supporting visuals or graphics
5. **Communication Strategist** → Optimize for SEO and distribution

**Example:** "Research AI in marketing and write a thought leadership post"

---

### Campaign Performance Analysis Workflow
**Trigger:** "Analyze [campaign] performance and present findings"

**Agent Sequence:**
1. **Data Strategist** → Analyze metrics and performance data
2. **Brand Strategist** → Assess brand impact and perception
3. **Communication Strategist** → Evaluate channel performance
4. **Presentation Builder** → Create visual presentation of findings
5. **Account Manager** → Prepare client presentation

**Example:** "Analyze Q4 holiday campaign and present results to client"

---

### Pitch Deck Development Workflow
**Trigger:** "Create a pitch for [prospect/opportunity]"

**Agent Sequence:**
1. **Brand Strategist** → Define positioning and key messages
2. **Communication Strategist** → Recommend channel approach
3. **Data Strategist** → Provide market insights and benchmarks
4. **Copywriter** → Craft compelling narrative and copy
5. **Presentation Builder** → Design the pitch deck
6. **Account Manager** → Coordinate internal review

**Example:** "Create a new business pitch for [prospect company]"

---

### Awards Submission Workflow
**Trigger:** "Submit [campaign] to awards"

**Agent Sequence:**
1. **Data Strategist** → Compile and quantify results
2. **Awards Agent** → Research categories and write case study
3. **Copywriter** → Refine narrative and headlines
4. **Presentation Builder** → Create supporting presentation materials
5. **Account Manager** → Obtain client approvals

**Example:** "Submit our sustainability campaign to Cannes Lions"

## 🤝 Handoff Protocols

### When Agent A Completes → Agent B Begins

#### Strategy → Creative Handoff
**From:** Brand Strategist or Communication Strategist
**To:** Copywriter or Art Director
**Deliverables to pass:**
- Messaging framework or brand positioning
- Target audience definition
- Key messages and proof points
- Channel specifications (if from Communication Strategist)

**Quality Check:**
- Are brand guidelines clear?
- Is the target audience well-defined?
- Are success criteria established?

---

#### Creative → Production Handoff
**From:** Copywriter or Art Director
**To:** Production Manager
**Deliverables to pass:**
- Final creative assets or concepts
- Technical specifications
- Asset requirements (formats, sizes, quantities)
- Timeline expectations

**Quality Check:**
- Are files production-ready?
- Are specs clearly documented?
- Is the production timeline feasible?

---

#### Data → Presentation Handoff
**From:** Data Strategist
**To:** Presentation Builder
**Deliverables to pass:**
- Raw data and analysis
- Key insights and findings
- Recommended visualizations
- Narrative recommendations

**Quality Check:**
- Is data accurate and verified?
- Are insights clearly articulated?
- Is there a clear story to tell?

---

#### Any Agent → Account Manager Handoff
**From:** Any specialist agent
**To:** Account Manager
**Deliverables to pass:**
- Completed work or recommendations
- Timeline and next steps
- Outstanding questions or decisions needed
- Client presentation materials (if applicable)

**Quality Check:**
- Is work client-ready?
- Are there any risks or concerns?
- What approvals are needed?

## 🚨 Special Routing Scenarios

### Urgent Requests
**Route to:** Account Manager FIRST
**Then:** Delegate to appropriate specialist(s)
**Reason:** Account Manager assesses feasibility, resources, and coordinates rapid response

---

### Budget-Sensitive Requests
**Route to:** Production Manager (for cost estimates)
**And:** Account Manager (for budget tracking)
**Include:** Relevant specialist for scope definition

---

### Client-Facing Deliverables
**Always include:** Account Manager in the workflow
**Reason:** Ensures client communication consistency and approval coordination

---

### Strategic Decisions
**Route to:** Brand Strategist (brand impact) + Communication Strategist (channel implications) + Data Strategist (performance implications)
**Reason:** Strategic decisions require multi-perspective analysis

---

## 💡 Pro Tips for Effective Routing

1. **When in doubt, route to Account Manager first** - They can coordinate complex requests
2. **Most requests need 2-3 agents** - Single-agent tasks are rare
3. **Always consider measurement** - Loop in Data Strategist for campaigns and initiatives
4. **Brand Strategist is foundational** - For new initiatives, start with brand alignment
5. **Production comes late** - Don't engage Production Manager until creative is approved
6. **Presentation Builder synthesizes** - Perfect for combining multiple agents' outputs
7. **Awards Agent documents** - Engage them to capture campaign stories in real-time

## 📊 Routing Decision Tree

```
Request Received
│
├─ Is it research/discovery on a brand? → Research Analyst
├─ Is it about brand/positioning? → Brand Strategist
├─ Is it about platforms/channels? → Communication Strategist
├─ Is it about data/performance? → Data Strategist
├─ Is it written content? → Copywriter
├─ Is it visual content? → Art Director
├─ Is it about meetings/clients/coordination? → Account Manager
├─ Is it about production/costs/vendors? → Production Manager
├─ Is it a presentation/pitch? → Presentation Builder
├─ Is it about awards/case studies? → Awards Agent
│
└─ Is it complex with multiple deliverables? → Multi-Agent Workflow
   ├─ Campaign → All Strategy + All Creative + Production + Account
   ├─ Content → Brand + Comms + Copy + Art
   ├─ Analysis → Data + Brand + Comms + Presentation
   ├─ Pitch → Research + Strategy + Copy + Presentation + Account
   └─ Brand Audit → Research + Brand + Comms + Data + Presentation
```
